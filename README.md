# Hi, I am Dr. AI Alchemy

I am interested in practical AI, prompt engineering, business analysis, data
analysis, and helping people turn AI tools into useful workflows.

## For A Novice Reader

This GitHub profile is a place to follow my AI learning and project-building
journey. I build small, understandable tools that show how AI can help with
research, decision support, dashboards, governance, analytics, and business
operations.

If you are new to AI, the main idea is simple: these projects explore how to use
AI responsibly, explainably, and practically instead of treating it like magic.

## For A Technical Reader

My repositories focus on applied AI workflow design: Streamlit dashboards,
planner-worker agents, deterministic validation layers, local-first prototypes,
audit logs, SQL-backed analytics, Python automation, TypeScript APIs, and
governance patterns for AI-assisted decisions. I am especially interested in
prompt engineering, data analysis, human-in-the-loop review, and turning model
outputs into structured, testable systems.
